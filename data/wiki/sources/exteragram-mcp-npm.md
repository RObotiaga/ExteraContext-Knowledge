## Manifest и экспортируемая поверхность

Опубликованный `package.json` задаёт ESM (`type: module`), `main: ./dist/index.js`, CLI `bin` с именем `exteragram-mcp` на тот же файл и Node.js `>=20.0.0`. В нём нет поля `exports` или `types`; `dist/index.d.ts` содержит только `export {}`. Поэтому опубликованное дерево содержит декларации модулей, но manifest не объявляет отдельный root TypeScript API. `dist/index.js` имеет Node shebang и стартует MCP stdio-сервер. Зависимости заявлены диапазонами `@modelcontextprotocol/sdk ^1.12.0` и `zod ^3.24.0`; `files` включает `dist`, а публикация также содержит package metadata, README и LICENSE.

В `dist/` ровно 96 файлов: 24 `.js`, 24 `.d.ts`, 24 `.js.map` и 24 `.d.ts.map`. Source maps указывают пути вроде `../../src/tools/adb.ts`, но не содержат `sourcesContent`; `src/` в tarball отсутствует.

README заявляет **76 tools / 18 groups**. В 18 опубликованных `dist/tools/*.js` насчитывается **81 статический вызов `server.registerTool(...)`**; `dist/server.js` подключает 18 регистрационных функций A–R. Это проверка текстовых вызовов в архиве, не MCP runtime discovery: пакет не запускался, поэтому число инструментов, фактически выдаваемых протоколом, не подтверждено. Расхождение 76/81 остаётся не объяснённым.

## Ограничения и пробелы

- Не запускались и не устанавливались пакет, его скрипты, зависимости или CLI; MCP handshake не выполнялся.
- Не проверялись опубликованная подпись npm отдельно, build provenance/attestation и воспроизводимость `dist/` из commit.
- В tarball нет vendored dependency files и package lock; фактическое разрешение semver-зависимостей не исследовалось.
- npm `prepublishOnly` — объявленная команда `npm run build && npm test`; документация npm помещает её в lifecycle `npm publish`, а не в `npm install`/`npm pack`. Само наличие строки не доказывает её успешный запуск для данного выпуска или успешные тесты. См. [npm lifecycle scripts](https://docs.npmjs.com/cli/v11/using-npm/scripts/).
- Фактическая выдача инструментов runtime не проверена; 81 — только статические вызовы регистрации, README утверждает 76.
- Утверждения README о поддерживаемых функциях/совместимости не независимо подтверждались клиентом ExteraGram.

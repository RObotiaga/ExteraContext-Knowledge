# fuckramochka/mioplugin — каталог Miogram, Python-примеры и Rust/WASM SDK

Источник: [репозиторий](https://github.com/fuckramochka/mioplugin), ветка `main`, зафиксированный commit [`b5eb7ee542635ae52cf5eabc622f1944e4148a56`](https://github.com/fuckramochka/mioplugin/tree/b5eb7ee542635ae52cf5eabc622f1944e4148a56); snapshot получен 2026-09-27. Репозиторий описывает себя как официальный каталог, SDK и экосистему Miogram; README прямо связывает его с клиентом Miogram ([README, строки 1–16](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/README.md#L1-L16)). Корневая лицензия — MIT ([LICENSE](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/LICENSE)); Rust crate отдельно указывает `GPL-3.0` в Cargo metadata ([Cargo.toml, строки 1–10](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/Cargo.toml#L1-L10)). Это код и документация Miogram, а не подтверждённый SDK ExteraGram/AyuGram. В рамках сбора ничего не запускалось, не собиралось и не устанавливалось; runtime-результатов нет.

## Что подтверждено кодом

### Python hooks и жизненный цикл в примерах

Во всех типичных примерах класс наследует `base_plugin.BasePlugin`; регистрация происходит из `on_plugin_load()`. Исходящие изменения используют `add_on_send_message_hook(priority=...)` и возвращают `HookResult(HookStrategy.MODIFY, message=...)` либо `DEFAULT`: так работают formatter, transformer, link cleaner, dice roller и styler ([Code Formatter](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/code_formatter/plugin.py#L18-L35), [Text Transformer](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/text_transformer/plugin.py#L48-L77), [Link Cleaner](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/link_cleaner/plugin.py#L54-L81)). Это конкретный pattern в исходниках примеров, но не реализация host dispatcher.

Incoming-примеры вызывают `add_hook("updateNewMessage", match_substring=True, priority=...)` и читают `update.message`; Auto Reaction проверяет `out`, `dialog_id` и `id`, затем вызывает `self.client.send_reaction(...)` ([Auto Reaction, строки 14–40](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/auto_reaction/plugin.py#L14-L40)). In-App Notifications показывает toast для непустого текста входящего сообщения ([строки 14–27](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/in_app_notifications/plugin.py#L14-L27)). Antispam Guard хранит скользящее окно из 12 строк в `deque`, сигнализирует при 4 повторах / 5 invite-ссылках / 6 URL и ограничивает toast cooldown 90 секундами; README говорит «incoming messages», но кодовое окно считает также количество URL, а отдельный общий минимум — 6 элементов ([код, строки 22–29, 32–85](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/antispam_guard/plugin.py#L22-L29), [README, строки 1–9](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/antispam_guard/README.md#L1-L9)). Состояние здесь — поля экземпляра плагина (`self.__dict__`), а не persistent storage.

### Конкретные техники примеров

- `code_formatter` реализует `.code`, `.inline`, `.spoiler`, `.quote`; у `.code` язык вставляется только когда первая строка без пробелов и длиной до 20 символов, иначе получается fenced block без языка ([код, строки 37–58](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/code_formatter/plugin.py#L37-L58)).
- `text_transformer` делает `.upper/.lower/.reverse/.mock/.uwu`, перебирая команды и модифицируя отправляемый текст. `mock` меняет регистр только букв, `uwu` заменяет r/l и добавляет `uwu` ([код, строки 20–45, 48–77](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/text_transformer/plugin.py#L20-L45)).
- `dice_roller` использует `random.SystemRandom`, ограничивает число кубиков диапазоном 1–20, число граней 2–1000 и drop-lowest числом меньше количества кубиков ([код, строки 22–70](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/dice_roller/plugin.py#L22-L70)).
- `link_cleaner` ищет HTTP(S)-URL регулярным выражением, очищает выбранные query-параметры, все `utm_*`, сохраняет остальные пары и fragment; ошибки очистки оставляют исходный URL ([код, строки 20–51, 54–71](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/link_cleaner/plugin.py#L20-L51)).
- `message_counter` держит in-memory счётчики входящих/исходящих событий, заменяет точный текст `.stats` отчётом и добавляет `MAIN_MENU` item для показа статистики через toast ([код, строки 19–47, 49–90](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/message_counter/plugin.py#L19-L47)). README прямо говорит, что счётчики сбрасываются при перезапуске и не покидают устройство ([README, строки 1–6](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/message_counter/README.md#L1-L6)).
- `quick_tools` в коде добавляет `MESSAGE_CONTEXT_MENU` item и показывает `message_id`/`dialog_id` в toast, хотя manifest/README обещают копирование ID, plain text и перевод ([код, строки 14–32](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/quick_tools/plugin.py#L14-L32), [manifest](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/quick_tools/manifest.json#L1-L14)).

`custom_profile` выделяется: Python-обёртка содержит строку с большим base64-сжатым DEX payload, проверяет распакованный SHA-256 перед записью, грузит `cpb.CpbNative` через `DexClassLoader`, передаёт legacy-настройки и при unload вызывает `core.unload()` ([обёртка, строки 20–32, 61–168](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/custom_profile/plugin.py#L20-L32), [DEX load/unload, строки 64–168](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/plugins/custom_profile/plugin.py#L64-L168)). Обёртка обращается к `ApplicationLoader.applicationContext`, `android_utils`, `client_utils`, `hook_utils` и `app.miogram.bridge.profile.CustomProfileEngine`; README/metadata одновременно содержит инструкции ExteraGram 12.5.1/12.8.1 и SDK >=1.4.0. Поэтому это пример привязки к конкретному Android host/bridge, а не переносимый Python-only API. Сам embedded DEX не исследован.

### Документированный API и точные границы доказательства

`HOOKS_REFERENCE.md` документирует модульные метаданные (`__id__`, `__name__`, `__description__`, `__author__`, `__version__`, optional `__icon__`, `__app_version__`) и lifecycle callbacks `on_plugin_load`, `on_plugin_unload`, `on_app_event` для START/RESUME/PAUSE/STOP ([строки 23–73](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/HOOKS_REFERENCE.md#L23-L73)). Отдельно `PLUGINS_DEV_GUIDE.md` заявляет Python через Chaquopy 3.11, Java/Kotlin extensions и WASM; в снимке нет host/build implementation, подтверждающей этот список. Также guide показывает `urllib.request` внутри `run_background` как сетевой рецепт, но не раскрывает cancellation/threading contract host ([runtimes, строки 1–17](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/PLUGINS_DEV_GUIDE.md#L1-L17), [background request, строки 147–162](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/PLUGINS_DEV_GUIDE.md#L147-L162)). Документ также описывает:

- message hook `add_on_send_message_hook(priority=...)`, `on_send_message_hook(peer,message,params)` и `HookResult(DEFAULT|MODIFY|CANCEL)` ([строки 77–110](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/HOOKS_REFERENCE.md#L77-L110));
- TL/MTProto `add_hook("messages.sendReaction", match_substring=False, priority=10)`, callbacks `pre_request_hook`, `post_request_hook`, `on_update_hook` ([строки 114–151](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/HOOKS_REFERENCE.md#L114-L151));
- меню `MenuItemData`/`MenuItemType`, пять перечисленных menu targets, callback context с dialog/message IDs ([строки 155–187](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/HOOKS_REFERENCE.md#L155-L187));
- Java method hooking через `find_class`, `hook_method((class, method), handler=MethodHook, priority=...)`, before/after parameters и `HookFilter` predicates ([строки 191–245](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/HOOKS_REFERENCE.md#L191-L245));
- `self.client` примеры send/delete/forward/reaction/file, Android toast/alert/UI-thread, settings rows, get/set/export/import settings ([строки 250–301](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/HOOKS_REFERENCE.md#L250-L301)).

Это `docs`-уровень. В Python source подтверждены лишь более узкие call-sites в examples: add outgoing hook, `updateNewMessage`, `self.client.send_reaction`, toast и один menu item. Java hooks, hook filters, request interception, полный `AccountClient`, SQLite/key-value `self.storage`, settings export/import и permissions не имеют реализации host-side в данном repo.

### Rust/WASM SDK — кодовый контракт

Crate `miogram-plugin-sdk` version `0.1.0`, edition 2021, `cdylib` + `rlib`, без зависимостей; release profile задаёт `opt-level=z`, `panic=abort`, stripping и overflow checks ([Cargo.toml, строки 1–22](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/Cargo.toml#L1-L22)). Фактический SDK экспортирует ABI revision 1: `miogram_abi_version()`, `miogram_alloc(i32)`, `miogram_guest_free(i32,i32)`, `miogram_call(*const u8,i32)->i64` ([lib.rs, строки 110–174](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/lib.rs#L110-L174)). Host должен выделять request из heap гостя, передавать frame и освобождать переданные регионы через guest allocator согласно ABI commentary ([lib.rs, строки 3–21](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/lib.rs#L3-L21)); устройство настоящего host allocator в снимке отсутствует.

Автор реализует `Plugin: Send` с одним методом `handle(&mut self, op: &str, payload: &[u8]) -> Result<Vec<u8>, i32>`; комментарий сообщает, что instance один на module и host сериализует вызовы. `register!(T)` экспортирует `miogram_create_plugin`, который задаёт factory; инстанс создаётся лениво перед первым dispatch, так как WAMR не исполняет constructor sections ([lib.rs, строки 43–108](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/lib.rs#L43-L108)). `miogram_call` декодирует запрос, ловит unwind для dev builds; ошибки кодируются как `-(code as i64)-1`, а response возвращает packed pointer/length ([lib.rs, строки 146–174](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/lib.rs#L146-L174)). Поэтому `-1` в README — обобщённое/неточное описание ошибки, не точная кодировка всех semantic codes.

Envelope v1 имеет 12-byte header: `MIOG`, version 1, 3 zero reserved bytes, little-endian `op_len`, UTF-8 `op`, остаток — payload. Код ограничивает `op_len` 128 и проверяет header/magic/version/reserved/UTF-8/truncation; encode/decode реализованы в `src/envelope.rs` ([строки 9–24, 44–90](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/envelope.rs#L9-L24)). Однако `MAX_TOTAL` объявлен как 4 MiB, а сумма при decode считается с `payload_len_hint()` равным нулю, поэтому проверка не учитывает фактический размер payload ([строки 22–24, 58–77](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/envelope.rs#L22-L77)). Это наблюдение исходника, не эксплуатационная проверка. В том же envelope module есть unit tests на roundtrip, empty payload, bad magic, truncated, wrong version и multibyte operation ([строки 93–143](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/envelope.rs#L93-L143)). `examples/echo.rs` обрабатывает только `echo` и `ping`, возвращая envelope; неизвестная операция возвращает `Err(1)` ([строки 1–25](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/examples/echo.rs#L1-L25)).

## Существенные противоречия и ограничения

1. README рекомендует модульные `__id__` и `BasePlugin.on_plugin_load/on_plugin_unload` ([README](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/README.md#L43-L68)); каталожные примеры это действительно используют. Но `PLUGINS_DEV_GUIDE.md` представляет другой `miogram.plugins.Plugin`, callbacks `on_load`, `on_message_send`, manifest `plugin.json` с `entrypoint`, `minAppVersion`, `permissions`, `settings` ([guide schema](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/PLUGINS_DEV_GUIDE.md#L22-L66), [hooks](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/PLUGINS_DEV_GUIDE.md#L70-L99)). Реальные catalog manifests используют `entry_point`, `min_app_version` и не содержат permissions/settings; samples используют `on_plugin_load` и `on_send_message_hook`. Не объединять эти две схемы в один подтверждённый контракт.
2. README заявляет безопасные permissions для internet/files/clipboard и WASM, guide приводит permission names и обещает runtime permission review ([README](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/README.md#L10-L16), [guide schema](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/PLUGINS_DEV_GUIDE.md#L33-L65), [install](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/PLUGINS_DEV_GUIDE.md#L166-L172)); actual sample manifests не перечисляют permissions, а host/security implementation не включена. Это только `docs` claims.
3. Для WASM источники расходятся: HOOKS_REFERENCE показывает `mio_init` / `mio_hook_on_send_message` и zip `.mioplugin` ([строки 305–322](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/HOOKS_REFERENCE.md#L305-L322)); Rust SDK фактически экспортирует `miogram_*` ABI и документирует `.wasm`, Ed25519 manifest, WAMR host и future FlatBuffers. В `sdk/.../README.md` для envelope ошибочно указан magic `HYPR`, тогда как код `src/envelope.rs` задаёт `MIOG` ([README, строки 44–74](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/README.md#L44-L74); [код envelope](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/sdk/rust/miogram-plugin-sdk/src/envelope.rs#L9-L24)). SDK README также называет response error `-1`, в то время как code использует `-(code)-1`.
4. Root README перечисляет пять плагинов, но catalog.json содержит одиннадцать; каталог в JSON включает шесть дополнительных tools (`text_transformer`, `dice_roller`, `link_cleaner`, `code_formatter`, `message_counter`, `antispam_guard`) ([README, строки 20–30](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/README.md#L20-L30), [catalog, строки 5–139](https://github.com/fuckramochka/mioplugin/blob/b5eb7ee542635ae52cf5eabc622f1944e4148a56/catalog.json#L5-L139)).

6. У репозитория нет подтверждения совместимости с ExteraGram/AyuGram: примеры import-ят Miogram-style `base_plugin`, `android_utils`; только Custom Profile явно содержит Miogram bridge class и одновременно указывает ExteraGram версии. ## Практические выводы

Для чтения и переноса полезны прежде всего конкретные call-site patterns примеров: исходящий pre-send rewrite с безопасным возвратом `DEFAULT`, incoming update filtering, context-menu item и локальные session counters. Проверять нужно против точной версии host SDK: документация и каталог расходятся по именам базового класса, callbacks и manifest schema. Не переносить Miogram API напрямую в ExteraGram/AyuGram; репозиторий не содержит plugin engine, который бы подтвердил эти импорты.

Для WASM ориентироваться на код `miogram-plugin-sdk` как на фактическую реализацию guest ABI, а не на упрощённый Rust pseudo-code из `HOOKS_REFERENCE.md`. Проверить host contract отдельно: host C/JNI implementation, allocator/free lengths, signature codec, sandbox resource limits и актуальную FlatBuffers schema отсутствуют. Кодовый `MAX_TOTAL` не ограничивает реальную payload length, что требует уточнения/исправления upstream до доверия к лимиту.

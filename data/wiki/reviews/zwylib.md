## Независимое покрытие

Сверены `snapshot.json`, полный `tree.json`, `file-manifest.json`, `radar-context.md`, пустой `radar-urls.json`, source page и все записи facts JSON. Радар указывает на использование ZwyLib в ExteraGram plugin runtime и зависимость SyncProfile; эти сведения оставлены за радаром/SyncProfile и не приписаны библиотеке без её подтверждения. Весь документационный раздел snapshot прочитан по 13 страницам MDX: [index](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/index.mdx#L1-L30), [async](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/async.mdx#L1-L133), [commands](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/commands.mdx#L1-L468), [hooks](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/hooks.mdx#L1-L247), [requests](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/requests.mdx#L1-L278), [settings](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/settings.mdx#L1-L342), [cachefiles](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/cachefiles.mdx#L1-L159), [ui](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/ui.mdx#L1-L373), [localization](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/localization.mdx#L1-L175), [logging and notifications](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/logging-and-notifications.mdx#L1-L363), [autoupdater](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/autoupdater.mdx#L1-L70), [plugins](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/plugins.mdx#L1-L192), [utilities](https://github.com/Zwylair/zwylib-docs/blob/69d56b4b64e5e61b47646282eb5ec749415ac142/content/utilities.mdx#L1-L395). Также прочитаны сайт-конфигурация и `package.json`; package-lock и favicon перечислены в дереве, но не сохранены в локальном acquisition и не нужны для оценки SDK API.

Покрытие включает документированные объявления и примеры команд/алиасов/аргументов/ошибок, sync и async command lifecycle, hook/reflection и safe mode, общий async loop и callback bridge, TL-запросы и updates pipeline, settings/cache, UI и picker outcomes, язык/подписки, autoupdater, plugin inventory/install/reload, Java interop/utilities, версии и build/debug границы. Отдельно отмечено, что `account` есть у command handler, но правила выбора/владения аккаунтом в `Requests` документация не задаёт.

Tree SHA и все локально полученные файлы, перечисленные в `file-manifest.json`, сверены с сохранёнными метаданными и контрольными суммами. В дереве отсутствует README и отдельная документация по коду SDK; `package.json` относится к сайту документации. Неполученные `package-lock.json` и favicon не закрывают пробелы API-документации.

## Найденное и исправленное

- Исходные 51 фактов покрывали основные темы, но machine layer пропускал несколько самостоятельных полезных API. Добавлены 12 записей `zwylib-052`…`zwylib-063`: `HookUtils.get_private_field`; plugin inventory/path/loading и reload; низкоуровневые SettingsManager get/reload/remove; AlertDialog; Java ArrayList обратное преобразование/deprecated helper; exception formatters; `create_bundle`; локально ограниченный `open_message`; снятие отдельной команды; получение/обновление locale; `SingletonMeta`.
- `zwylib-041` называл `package.json`-свидетельство `unavailable` и ссылался на корень репозитория. Исправлены evidence permalink на сам файл с диапазоном строк и статус на `docs`. `zwylib-040` сохранён как `unavailable`: отсутствие SDK tests/examples — отрицательное свидетельство по дереву snapshot, а не описание API.
- В source page дополнены строки API о reflection, plugin inventory/reload, SettingsManager, AlertDialog, locale callbacks, cleanup одной команды, Java/Python conversion, Bundle, форматировании исключений и предпосылке локальной доступности peer.
- Проверены сигнатуры/описания по конкретному SHA. В частности, `get_message` возвращает контейнер `messages_Messages`, `pick_chat` документирует exception при cancel, тогда как текстовый и selector dialogs возвращают `None`; `safe_open_message` является coroutine. Противоречий между перечисленными контрактами в просмотренных страницах не обнаружено.

## Дубликаты и канонизация

Повторяющихся `claim` строк внутри 63 записей не обнаружено; IDs уникальны. Некоторые тематические контракты представлены общими и конкретными записями для разных call-site (например, общий `safe_func_call` и его применение к `BottomSheet`, `ensure_media_downloaded` и его использование установщиком); это не дубль одного утверждения. В будущем объединять по каноническим темам `async`, `threading`, `lifecycle`, `commands`, `hooks`, `network`, `accounts`, `storage`, `ui`, `localization`, `distribution`, `workflow`, `debug`, `build` и `portability`, сохраняя `zwylib` как provenance. Контракты ExteraGram docs нельзя сливать с похожими API AyuGram/iOS/Desktop без отдельного подтверждения совместимости.

## Остаточные gaps

- В snapshot нет реализации самой ZwyLib, тестов SDK, release tag/changelog или таблицы соответствия версий API. Поэтому заявления о сигнатурах и автоматической очистке — **docs**, не `code` или `runtime-verified`; фактическое поведение при unload требует проверки реализации.
- Нет общих правил UI thread, thread-safety/cache atomicity, settings migration, persistence namespace по аккаунту, авторизации/rate limits, сети/подписи auto-update, доверия к устанавливаемым plugin-файлам либо подтверждения результата reload/install.
- Внешние ссылки на `BasePlugin`, settings components и bulletin helper не входили в закреплённый snapshot; неизвестно, совпадают ли их контракты с данным набором документов. `package-lock.json` и бинарный favicon не приобретались.
- `package.json` сообщает о сайте version `1.0.0`, но этот номер не устанавливает версию API ZwyLib. Публичная версия библиотеки и поддерживаемые версии клиента остаются неуказанными.

Эти пробелы ограничивают выводы документационным контрактом и оправдывают вердикт `accepted-with-gaps`; абсолютная полнота реализации или совместимость с какой-либо сборкой клиента не заявляется.

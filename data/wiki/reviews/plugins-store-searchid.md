# Ревью фактов SearchID

Проверены утверждения сборщика по исходнику `Plugins/SearchID.plugin` на commit `997557613ba8132f8373e34a6cf8038eb9f87c12`.

Сборщик предоставил 5 фактов. Принято 5 фактов: три скорректированы, два подтверждены без изменения.

| Факт | Решение | Результат проверки |
|---|---|---|
| `searchid-001` | Скорректировать | Исходник подтверждает вызов `getMethods("fillItems")`, проверку результата и передачу первого элемента в `hook_method()`, а также запасной вызов `hook_all_methods()`. Обобщённое утверждение о поведении API без указания типов аргументов не подтверждается одним этим файлом. |
| `searchid-002` | Скорректировать | Исходник подтверждает вызов `get_private_field()` для `query` и последующую нормализацию результата. Общая гарантия доступа к приватным полям не установлена исходником плагина. |
| `searchid-003` | Скорректировать | Исходник проверяет состояние поиска, непустой запрос и значения `None`, затем при совпадении задаёт результат с именем и ID. Это не эквивалентно проверкам истинности ID и имени из исходного recipe сборщика. |
| `searchid-004` | Скорректировать | Вызов helper и его аргументы подтверждены. Код также показывает формирование traceback и передачу его callback копирования; само поведение helper по отображению уведомления не проверяется этим исходником. |
| `searchid-005` | Одобрить | Код подтверждает попытку снять каждый сохранённый hook, подавление исключений и сброс списка и состояния плагина. |

Все принятые факты имеют статус `code`, точные диапазоны `evidence_path` и URL, привязанные к проверенному commit SHA. В итоговых утверждениях отделено непосредственно наблюдаемое поведение плагина от общих гарантий API, не устанавливаемых данным исходником.

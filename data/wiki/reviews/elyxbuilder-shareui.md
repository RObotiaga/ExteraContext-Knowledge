## Проблемы и исправления

- README quick start показывает `elyb new "My Plugin" myname`, но parser не объявляет positional arguments. Также `--gen` dispatch вызывает `runNew(pluginname, author, zipformat)`, тогда как `runNew` объявлена с двумя параметрами. Исправлены source page и fact 027: интерактивный путь отдельно вызывает `runInteractive()`, а fast-generation mismatch помечен как вывод из сигнатур. CLI не запускался.
- Русская и английская obfuscation docs используют ключ `obfuscation` и говорят, что `removeLogs` работает без obfuscation flag. Код загружает `obfuscationConfig`; loader добавляет defaults и удаляет legacy `RemoveLogs`, записанный scaffold. Путь `--obfuscation` в `runBuild` — единственное место, где вызывается obfuscation pipeline. Fact 028 и source page теперь явно фиксируют расхождения без утверждения о runtime-эффекте.
- Source page ранее не описывала контракты ignore helper commands и stats, хотя их документы и CLI source есть в снимке. Добавлены краткое описание и fact 029; они не объединены с разными ignore-эффектами build facts.
- Уточнён fact 014: новый случайный XOR key относится к строковому encoding, если соответствующий obfuscation этап включён. Fact 017 теперь также отражает `--no-info`, выключающий ZIP metadata insertion.
- Watch распознаёт build failure только по трём текстовым маркерам плюс process status. Отказ encryption при отсутствии `pyzipper` печатает другой текст, штатно возвращает управление и может отобразиться как успешная сборка с fallback path; source page и fact 026 фиксируют этот static-analysis gap.
- Обе языковые docs считают отдельные `--obfuscation FILE` пути от корня проекта, код же сравнивает пути относительно `source`. Это отражено в source page и fact 030.

## Проверка повторов и оставшиеся gaps

ID и формулировки 30 facts сверены на повторное представление одного контракта: refmap precedence, scaffold output, archive filters, bytecode cache, metadata, watch и docs/code contradictions описывают разные поведенческие границы. Пересечения между fact 020/021/026 намеренные: polling/change detection, `latest` output и преобразование ошибок в watch UI — отдельные контракты. Повторы с другими источниками могут сохраняться с отдельным provenance; канонические темы для синтеза — `build`, `workflow`, `watch`, `metadata`, `locales`.

Остаются ограничения: `elyb.elyxdsl.interpreter` отсутствует, поэтому реализацию и безопасность DSL runtime подтвердить нельзя; в репозитории нет client plugin loader, import resolver, lifecycle dispatch, dev server, загрузчика assets/locales или locale fallback; отсутствие тестовой suite в pinned tree означает, что build/cache/archive контракты не подтверждены тестами. Не устанавливались зависимости и не запускались CLI/build/архивы; не проверены runtime-приём `.eaf`, шифрование у клиента и совместимость с Elyx/ExteraGram. Эти ограничения не дают трактовать документацию инструмента как подтверждение runtime поведения.

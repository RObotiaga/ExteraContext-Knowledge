# Пробелы, ограничения и противоречия

Материалы считаются обработанными в зафиксированной области чтения. Независимая проверка не превращает недоступный код или непроверенную совместимость в установленный факт. Подробные остаточные пробелы находятся в [отчетах источников](source-registry.md).

## Общие ограничения

- Runtime на Android/iOS/Desktop не запускался. Сигнатуры подтверждены документами или конкретным исходным снимком.
- Официальные docs называют baseline SDK 1.4.4.3, а отдельные разделы требуют более новых API. PySDK 1.4.5.5 из радара — отдельный контекст; [подробности](sources/official-sdk.md).
- Официальный release stream SDK теперь зафиксирован отдельно: [official-sdk-builds](sources/official-sdk-builds.md) хранит build/tag/commit и digests. Содержимое stubs.zip пока не разобрано, поэтому точный symbol-level version map остаётся пробелом.
- В экспортированном радаре потеряны часть имен и ссылок. JSON добавляет сообщения, но не восстанавливает все пустые клетки. [Проверенный реестр](source-candidates.json) хранит aliases и unresolved identities.
- APK Opexgram beta4 представлен метаданными. Документация beta6 и Telegram-анонс не заменяют этот бинарный артефакт.
- Неустановленные имена и недоступные материалы сохраняются в реестре и самостоятельных отчетах; подтвержденный API для них не выдумывается.

## Противоречия, полезные разработчику

- Документация и actual cleanup могут расходиться: [for-vibecoders](sources/for-vibecoders.md), [AltyLib](sources/altylib.md).
- Заявления build-tool README и implementation annotations проверяются отдельно: [Gradle-конвейер](sources/gradle-plugin.md).
- Совпадение названия плагина, пакета, каталога или зеркала не доказывает равенство содержимого. [Распространение](topics/distribution.md).

## Проверенные конфликты и неустановленные утверждения

- **SDK version gates:** вводная официальной документации указывает 1.4.4.3, а подстраницы используют 1.4.5.0+ для multi-account и 1.4.5.3+ для Elyx. Требование app 12.6.4 для Intents относится к этому API отдельно. [Матрица и ссылки](compatibility.md).
- **Lifecycle между docs и stub:** примеры `exteraGram-docs` используют `on_load`, а полученный отдельно stub `exteragram-utils` 0.1.3 объявляет `on_plugin_load`/`on_plugin_unload`. Это разные версии и артефакты; текущий runtime контракт не выводится из их похожих назначений. [Источник docs](sources/exteragram-docs.md) · [package](sources/exteragram-utils.md) · [сравнение](compatibility.md).
- **Кеширование Gradle:** README называет основные `buildDex*` tasks задачами только с up-to-date checks, но `BuildDexTask` отмечен `@CacheableTask`. Настоящее поведение надо устанавливать на Gradle consumer build; его здесь не запускали. [Факт](facts/gradle-plugin.json) · [отчёт](reviews/gradle-plugin.md).
- **PLEngine runtime callback:** RObotiaga README говорит об успешном Python→JVM callback; ROADMAP того же commit оставляет JVM plugin unload/load ошибку на AyuGram 12.9.0. В snapshot нет связанного с заявлением артефакта/лога. Независимая проверка оставляет execution неподтверждённым. [Источник](sources/template-robotiaga.md) · [review](reviews/template-robotiaga.md).
- **Unload lifecycle:** в AltyLib `HookLifecycle.cancel_all` нужно вызвать явно; `on_plugin_unload` этого не делает. Некоторые hook handles и NotificationCenter observer не привязаны к unload. Это отличается от шаблонов, где cleanup управляется централизованно. [AltyLib](sources/altylib.md) · [канонические правила](rules.md).
- **TTL и README AltyLib:** `TTLCache` — in-memory, чтение не продлевает TTL, нулевая TTL означает отсутствие expiry, eviction не является LRU. README расходится с реализацией validator и некоторыми примерами. [Факты](facts/altylib.json) · [review](reviews/altylib.md).
- **Возможность SDK каталога:** Catalib включает facade и инструменты, но repository snapshot помечен archived, README говорит о прекращении поддержки и не описывает миграцию на ElyxCore. Заявленный автором parity SDK не был сверён со всеми актуальными сборками. [Источник](sources/catalib.md) · [review](reviews/catalib.md).
- **Инструмент с названием patcher:** описание `exteralib` говорит о сборке plugin DEX, а code snapshot показывает APK→JAR CLI и изменение class-file major version. В нем не найдены hooks/loader/lifecycle API. [Источник](sources/exteralib.md) · [review](reviews/exteralib.md).
- **Исполняемый SDK против типовых заглушек:** wheel exteragram-utils 0.1.3 содержит типовые объявления SDK и developer CLI; сам клиентский backend и серверная часть протокола в пакете отсутствуют. Независимая проверка также уточнила ограничения TCP reader и показала, что CLI-команды не тождественны описанному протоколу. [Источник](sources/exteragram-utils.md) · [review](reviews/exteragram-utils.md).
- **Счётчик инструментов MCP:** README/docs ExteraGram MCP называют 76 инструментов; снимок кода содержит 81 регистрацию `it(...)` и 101 объявление. Тесты/сборка, ADB и совместимость с клиентом не запускались. [Источник](sources/exteragram-mcp.md) · [review](reviews/exteragram-mcp.md).
- **README-only skill:** pinned `faustyu1/exteragram-plugins-skill` содержит только README; заявленный `plugin-development/SKILL.md` и вспомогательные paths независимо проверены pinned URL и отсутствуют. Оставлены только подтверждённые README claims, противоречия `.plugin`/base64/ADB не разрешены. [Источник](sources/skill-faust.md) · [review](reviews/skill-faust.md).
- **mioplugin catalogue и лицензия:** README перечисляет пять записей, а вложенный каталог — одиннадцать; root заявляет MIT, Rust/WASM SDK — GPL-3.0.

# Происхождение релиза и обновления

GitHub source, зеркало каталога и опубликованный пакет могут различаться. У каждой поставки сохраняйте самостоятельную идентичность и hash.

1. Сверьте metadata версии и repository URL. Зафиксируйте исходный SHA, опубликованные файлы и контрольные суммы.
2. Сопоставьте содержимое mirror/npm/packaged artifact с ожидаемым исходником. Redirect или одинаковое имя не заменяют эту проверку.
3. Для исполнения удаленного кода изучите фактическую проверку происхождения/подписи и trust root. Отличайте целостность загрузки от авторства.
4. Сохраняйте reviewer notes, ограничения лицензии и результат установки для выбранного хоста.

# Цикл установки, reload и диагностики

Разработческий сервер, отладчик и developer CLI решают разные задачи. В wiki храните фактическую последовательность для выбранного инструмента.

1. Определите установленный app/SDK и доступный backend. Получите путь плагина и убедитесь, что helper обращается к нужному приложению/устройству.
2. Передайте исходник или релизный пакет через поддерживаемый install путь; проверьте validation и результат каждой стадии.
3. Выполните reload и запросите состояние/логи. Сопоставьте ожидаемые imports/hooks со реально зарегистрированными.
4. При неудаче сохраняйте ошибку и версию. Разделите ошибку передачи, загрузчика, Python импорта, reflection и обработки события.

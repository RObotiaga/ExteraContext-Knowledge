# Инструменты разработки и управление клиентом

Проверяйте транспорт, discovery устройства, команды install/reload/logs и восстановление после ошибки. Префикс MCP или CLI сам по себе не подтверждает доступ к UI либо наличие всех инструментов в конкретной версии.
